# KNOXY APP 1.0

Assistente gratuito para AION 2 South America. [Baixar o instalador para Windows 10/11 64 bits](https://github.com/BrunoMPVieira/knoxy-app-downloads/releases/latest/download/KNOXY-APP-1.0-Installer.exe) (aprox. 217 MiB).

O instalador inclui o aplicativo, mapas, imagens e bibliotecas. Não exige Python. Na primeira abertura, siga o guia para verificar/instalar o Npcap e informe seu nick em South America. O KNOXY consulta o perfil público da NCSOFT; para a sincronização completa, mantenha o app aberto ao entrar no personagem. Ele nunca solicita sua senha da NCSOFT.

Atualizações são consultadas pelo app, verificadas por SHA-256 e instaladas ao fechar o KNOXY. Os dados do personagem ficam no computador e são preservados ao atualizar ou desinstalar. O instalador pode exibir o aviso de editor desconhecido do Windows porque não tem assinatura Authenticode.

O app é gratuito. Doações opcionais: [LivePix Kharnoxy](https://livepix.gg/kharnoxy). As bibliotecas de código aberto mantêm suas licenças, incluídas no instalador.
