# KNOXY APP

Canal oficial de downloads e atualizações do KNOXY APP para Windows 10/11 de 64 bits.

O aplicativo é gratuito. Baixe o instalador em Releases e siga o tutorial de Npcap e conexão do personagem pelo nick em South America.

Doações opcionais: https://livepix.gg/kharnoxy
